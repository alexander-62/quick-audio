# QuickAudio

**Выход звука и микрофон прямо в «Быстрых настройках» Windows 11.**

[Скачать](https://github.com/alexander-62/quick-audio/releases) · [Сообщить о проблеме](https://github.com/alexander-62/quick-audio/issues) · [English](README.md)

## Установка

Скачайте `QuickAudio-Setup-0.1.1-x64.exe` из Releases и запустите установщик.
При установке можно включить запуск вместе с Windows. После установки нажмите **Win + A**.
QuickAudio появится над стандартными плитками. Установка выполняется для текущего
пользователя без прав администратора.

Версия **0.1.1** видна в настройках панели, окне управления, свойствах программы
и названии установщика. При сообщении об ошибке укажите её и сборку Windows из `winver`.

Для Windows 11 24H2 и новее на x64. ARM64 не поддерживается. Проверена сборка 26300.9457;
совместимость с остальными сборками пока не подтверждена. Интерфейс программы — русский.

## Управление и автозапуск

Откройте **QuickAudio** через меню «Пуск»:

- **Включить** — добавить селекторы в системную панель.
- **Выключить** — убрать селекторы до следующего запуска.
- **Запускать вместе с Windows** — включить или выключить автозапуск.
- **Папка настроек** — открыть сохранённые настройки и локальный журнал.

Закрытие окна управления не останавливает работающую панель.
Выключение панели на текущий сеанс не выключает автозапуск.
Тот же флажок автозапуска доступен в настройках внутри Win + A.

Portable ZIP: распакуйте в постоянную папку, запустите `QuickAudio.exe` и нажмите «Включить».
Если включён автозапуск, не перемещайте папку без повторного включения этого флажка.

## Выходы, микрофоны и названия

Нажатие строки выбирает системное устройство по умолчанию. Отметка обновляется
после подтверждения Windows. Выход и микрофон выбираются независимо.
«Также для звонков» применяет следующие переключения и к устройству связи.
Снятие этого флажка само по себе не меняет выбранное устройство для звонков.

Нажмите шестерёнку рядом с «Также для звонков». Настройки открываются внутри панели:
есть прокрутка и кнопка «Назад», меню не выходит за верхнюю границу окна.

- Флажок рядом с устройством показывает или скрывает его строку.
- Устройство занимает одну строку: флажок, название и карандаш.
- Нажмите карандаш: название станет полем ввода, а карандаш — **✓**.
- Введите своё название и нажмите **✓** или **Enter**. **Esc** отменяет редактирование.
- Пустое поле и сохранение возвращают исходное имя.
- Исходное имя остаётся в подсказке, если задано своё название.

Настройки запоминаются по идентификатору устройства и сохраняются после перезапуска.
Скрытие не отключает устройство и не меняет текущий выход или микрофон.
Обновления подключений и выбора в других программах приходят через события Windows.
Небольшой индикатор переключения занимает постоянное место и не меняет высоту панели.

Программы с явно выбранным устройством могут продолжать использовать его.
Некоторым приложениям нужен перезапуск воспроизведения или записи для применения нового выбора.

## Обновление и удаление

Для обновления установите новый выпуск поверх текущего. Настройки сохранятся.
Автоматической проверки обновлений в версии 0.1.1 нет.

Удаление: Windows → Установленные приложения → QuickAudio → Удалить.
Автозапуск удаляется. Во время обновления или удаления закрывается именно тот
процесс ShellHost, который удерживает DLL QuickAudio. «Быстрые настройки» можно
сразу открыть заново; перезагрузка компьютера не требуется.

Настройки остаются в `%LOCALAPPDATA%\QuickAudio\settings.ini` для повторной установки.
Там же находится локальный журнал с ротацией примерно при 1 МиБ.
Если ShellHost не может записать этот журнал, его диагностика сохраняется
в `QuickAudio.Hook.log` рядом с программой.
Аудио и микрофон не записываются, телеметрия не отправляется. Сам агент не выполняет сетевые запросы.

## Ограничения

Это ранний выпуск 0.1.1. Внутренняя разметка Windows и интерфейс
PolicyConfig могут изменяться при обновлениях ОС. Может потребоваться адаптация.
Неизвестная разметка записывается в журнал. Файлы выпуска пока без цифровой подписи.

## Исходники

Visual Studio 2022, C++/WinRT, Windows SDK (проверен 10.0.26100.0): `scripts\build.cmd`.
Установщик: Inno Setup 6 и `scripts/package.ps1`. Готовые файлы появляются в `dist/`.
Visual C++ Runtime включён статически, отдельный Redistributable не требуется.
Инструкции разработчика и проверки находятся в `docs/`.
