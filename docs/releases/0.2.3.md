# QuickAudio 0.2.3

## Русский

Исправлена ошибка, при которой окно управления переключалось на English, а панель
Win + A оставалась на русском даже после выключения и включения.

Теперь выбранный язык передаётся из приложения в системную панель вместе с её
состоянием. Панель получает одно и то же значение языка независимо от каталога
настроек процесса Windows. Текст обновляется без перезапуска панели.

Обновите программу поверх установленной версии. Выбор языка, названия устройств,
переименования, скрытые устройства и настройки звука сохраняются.

## English

Fixed controls switching to English while the native Win + A panel remained in
Russian. The backend now publishes the selected language through IPC. The hook
uses this confirmed state instead of reading language settings from ShellHost's
local environment. Controls wake the backend immediately after a language change.

Install over the current version to preserve preferences.

## Validation

Language tests cover a mismatched client preferences path and stable translated
text from the backend value. A live-agent regression test switches Russian,
English, and Automatic, verifies state revisions, unchanged audio defaults and
device preferences, and restores the original language. Publication requires
Windows compilation, version checks, language tests, updater tests, packaging,
and uploaded asset verification.

Windows 11 24H2 or later, x64. ARM64 is unsupported; binaries remain unsigned.
