# QuickAudio 0.2.6

## Русский

Откат проблемных изменений расчёта высоты из 0.2.4 и 0.2.5 после сообщения об исчезновении панели при наведении мыши.

Удалены обработчик LayoutUpdated, обход визуального дерева для измерения подписей, изменения минимальной высоты системных строк и общий адаптивный viewport. Возвращено поведение размеров из 0.2.3.

Сохранены выбор языка, исправление его синхронизации, небольшая шестерёнка рядом с «Устройства вывода» и «Также для звонков» в настройках.

Это исправление регрессии, а не подтверждённое устранение обрезания плиток. Обрезание с карточкой проигрывателя может оставаться. Проверка стабильности на реальном рабочем столе ещё требуется.

## English

Roll back the adaptive sizing changes from 0.2.4/0.2.5 following a report that the panel disappears on mouse hover. Remove LayoutUpdated-driven visual-tree traversal, native row-minimum overrides, and the adaptive shared viewport. Restore 0.2.3 sizing behavior while keeping language synchronization and the compact controls.

Native tile clipping with a media card may remain. Interactive desktop validation is pending.
