# QuickAudio 0.2.5

## Русский

Исправлен расчёт высоты системных строк: версия 0.2.4 сохраняла уже выделенный размер, который мог не вмещать подписи нижнего ряда плиток.

Теперь учитываются размеры видимых дочерних элементов и подписи плиток. Системная строка получает необходимый запас, а место для аудиопанели уменьшается на ту же величину. Измеренный запас сохраняется при повторных проходах разметки. При нехватке места списки аудиоустройств прокручиваются.

Компактная шестерёнка, настройка «Также для звонков» в меню и выбор языка сохранены.

## English

Native row sizing now accounts for visible child content and tile captions rather than retaining an already-clipped arranged height. Extra native height is reserved and subtracted from the audio viewport, retaining that reservation across layout passes. Device lists scroll when space is limited.

## Validation

Windows compilation, version checks, updater/language tests, layout regressions, and packaging must pass before publication. Caption-overflow tests verify extra native space reduces the custom viewport and is retained on subsequent layout passes. Release asset sizes and SHA-256 are verified before publication.

The user's actual desktop, media-card presence, and tile-caption visibility still require an interactive check after installation. Windows 11 24H2 or later, x64; binaries are unsigned. GPL-3.0-or-later.
