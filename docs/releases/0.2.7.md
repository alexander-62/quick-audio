# QuickAudio 0.2.7

## Русский

Добавлены проверка сохранения и диагностика настроек устройств:

- Названия и видимость подтверждаются только после записи, сброса на диск и проверки значения.
- Ошибка записи больше не может выглядеть успешной при нулевом коде Win32.
- При отсутствии пути настроек программа не создаёт settings.ini в случайной рабочей папке.
- Если файл невозможно прочитать, это показывается как ошибка, а не как стандартные настройки.
- Кнопка «Папка настроек» при включённой панели создаёт QuickAudio-diagnostics.txt и открывает папку работающего агента.
- В отчёте указаны версия, путь программы и настроек, текущие ID устройств и сохранённые имена/видимость. Журнал содержит даты и сведения о пути и устройствах.

Причина конкретного сброса на компьютере пользователя ещё не установлена. Отчёт позволяет проверить, читается ли другой файл или сохранённые ID не совпадают с активными устройствами. Отсутствующий ID также может означать отключённое устройство. Имена автоматически на другие устройства не переносятся.

Изменения расчёта разметки из 0.2.4/0.2.5 не возвращаются.

## English

Device preference writes are flushed and verified before acknowledgement. Missing settings paths cannot fall back to a relative file, unreadable settings produce an error, and zero Win32 error codes cannot turn failed writes into success.

With the panel enabled, **Settings folder** asks the running agent to generate **QuickAudio-diagnostics.txt** and opens its actual folder. The report includes version, executable/settings paths, active endpoint IDs, aliases/visibility, and stored IDs absent from the active list. A disconnected device may also be absent. No automatic alias migration is performed.

The root cause of the user's reported reset is not yet confirmed. The unstable adaptive layout changes remain removed.

## Validation

Publication requires Windows x64 compilation, version checks, updater/language tests, and cross-process device preference persistence tests. Tests cover Unicode/quoted aliases, visibility for both flows, clearing preferences, preservation of unrelated entries, locked/missing files, and missing LOCALAPPDATA. Uploaded file sizes and SHA-256 are checked before publication.

Desktop reboot behavior and the user's current endpoint IDs still require a report from the user's computer. Windows 11 24H2 or later, x64; unsigned binaries. GPL-3.0-or-later.
