# QuickAudio 0.2.1

## Русский

Добавлен английский интерфейс панели Win + A, настроек устройств, окна управления и обновлений, включая подсказки, названия для экранного диктора и сообщения об ошибках. При русском языке интерфейса Windows QuickAudio использует русский, при остальных — английский. Названия устройств Windows и пользовательские переименования сохраняются.

После смены языка интерфейса Windows перезапустите QuickAudio. В установщик и portable ZIP включены обе README. Лицензия остаётся GPL-3.0-or-later; её условия пояснены в документации.

### Скачать и обновить

- **QuickAudio-Setup-0.2.1-x64.exe** — установщик для текущего пользователя без прав администратора. Можно установить поверх предыдущей версии; настройки сохраняются.
- **QuickAudio-Portable-0.2.1-x64.zip** — распакуйте в постоянную папку и запустите QuickAudio.exe.
- **SHA256SUMS.txt** — контрольные суммы.

В версии 0.2.0 можно нажать «Проверить обновления». Для portable обновление ZIP выполняется вручную.

## English

Added English throughout the Win + A panel, device settings, controls, and updates, including tooltips, accessibility labels, and error messages. QuickAudio uses Russian for a Russian Windows display language and English otherwise. Windows device names and custom aliases are unchanged.

Restart QuickAudio after changing the Windows display language. Both READMEs are included in the installer and portable ZIP. The license remains GPL-3.0-or-later, with a plain-language explanation in the documentation.

Download the Setup EXE for a per-user installation or the portable ZIP for a stable folder. Install over the previous version to keep preferences. Version 0.2.0 can find this release using **Check for updates**; portable updates remain manual.

## Validation / Проверки

Windows x64 compilation, version metadata checks, updater validation tests, installer compilation, and portable packaging pass before publication. Language-selection checks cover Russian regional variants, English, and other-language fallback. Asset sizes and SHA-256 are checked against GitHub before the draft is published.

A visual desktop check of the English interface has not yet been performed.

Windows 11 24H2 or later, x64. The existing desktop compatibility check was on build 26300.9457; other builds are not yet verified. ARM64 is unsupported. Release binaries are unsigned.
