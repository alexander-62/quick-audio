# QuickAudio 0.2.4

## Русский

Аудиопанель стала компактнее:

- «Также для звонков» перенесён в настройки.
- Уменьшенная шестерёнка расположена в одной строке с «Устройства вывода».
- Списки и настройки используют общую прокрутку по доступной высоте.
- Расчёт места учитывает рабочую область монитора, масштабирование и верхнюю карточку проигрывателя. При изменении разметки высота пересчитывается.
- Исходная высота системных строк резервируется, чтобы плитки Windows не сжимались под ползунками. При отключении панели исходные ограничения восстанавливаются.

Настройки языка, имена и видимость устройств сохраняются. Для обновления нажмите «Проверить обновления» или установите новый EXE поверх предыдущей версии.

## English

The audio panel is more compact. **Also for calls** is now in settings, and the smaller settings gear sits beside **Output devices**.

Both custom pages share a scroll viewport sized for the monitor work area, DPI, and vertically adjacent cards such as the media player. Layout changes recalculate the budget. Native row heights are reserved to avoid squeezing Windows tiles under the sliders, and original constraints are restored when the panel is removed.

Language choices, device names, and visibility preferences are preserved.

## Validation / Проверки

Publication requires Windows x64 compilation, version checks, updater and language regression tests, layout-budget tests, and packaging. Budget tests cover media-card presence, small and large work areas, nonnegative limits, and 150%/200% DPI conversion. Uploaded asset sizes and SHA-256 are verified before publication.

The actual Quick Settings layout with and without media playback still needs an interactive desktop check on the user's Windows build.
