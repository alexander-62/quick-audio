# QuickAudio 0.2.2

## Русский

Добавлен ручной выбор языка **Автоматически / Русский / English**. Он находится под флажком **Запускать вместе с Windows**:

- в окне управления QuickAudio;
- в настройках панели Win + A (шестерёнка рядом с «Также для звонков»).

Выбор применяется без перезапуска, синхронизируется между двумя окнами и сохраняется после повторного запуска. «Автоматически» использует русский при русском языке интерфейса Windows и английский при остальных.

Названия устройств, пользовательские переименования, видимость устройств и выбранные выходы/микрофоны не изменяются.

## English

Added a manual **Automatic / Русский / English** language selector below **Start with Windows** in both QuickAudio controls and the Win + A panel settings (the gear beside **Also for calls**).

The selection updates both interfaces without restarting and is saved for future launches. Automatic follows the Windows display language, using Russian for Russian and English otherwise. Device names, aliases, visibility, and audio defaults are unchanged.

## Скачать / Download

- **QuickAudio-Setup-0.2.2-x64.exe** — per-user installer; install over the previous version to preserve preferences.
- **QuickAudio-Portable-0.2.2-x64.zip** — portable package; replace the previous portable files manually.
- **SHA256SUMS.txt** — file checksums.

В QuickAudio 0.2.0 и 0.2.1 нажмите **Проверить обновления** / **Check for updates**.

## Validation / Проверки

Publication requires successful Windows x64 compilation, version checks, updater tests, language-selection and persistence tests, and packaging. Language tests use an isolated settings folder and cover forced Russian/English, automatic fallback, invalid preferences, synchronization after an external preference write, and preservation of Unicode aliases. Release asset sizes and SHA-256 are checked before publication.

Interactive desktop checks of the new selector, focus, and scaling have not yet been performed.

Windows 11 24H2 or later, x64. ARM64 is unsupported. Release binaries are unsigned. License: GPL-3.0-or-later.
